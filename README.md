## 📌 About the Project

This project is a **simple cryptocurrency exchange UI simulation** built using **HTML, CSS, and JavaScript**.

It allows users to:
- Buy cryptocurrency
- Sell cryptocurrency
- Simulate conversion between units and price (Toman)

This is a **front-end educational project** designed to practice DOM manipulation and interactive UI design.

---

## ✨ Features

- 💰 Buy / Sell / Convert buttons (tab system)
- 📊 Live price calculation based on input
- 🔢 Automatic price update using JavaScript
- 🎯 Interactive fieldset focus effect
- ⚡ Real-time input handling (keyup / onchange)
- 🎨 Clean UI inspired by crypto exchange platforms
- 🧠 Beginner-friendly JavaScript logic
